# あいうえお あそび

4〜5歳向けの ひらがな・カタカナ 学習アプリ（Androidタブレット想定のWebアプリ / PWA）。

## あそび
- **きいて あてよう**
  - 1もじ: 読み上げた文字を3つから選ぶ（10問で おいわい）
  - ことば: 絵と音声のことばを あいうえお表で打つ（かんたん＝3文字以内・濁音なし／むずかしい）。2回まちがえると正解のキーが光る
- **おして きこう**: あいうえお表をタップすると その文字を読み上げ、🔊 で並べたことば全体を読む
- **かいて みよう**: 指でなぞって書く。1画ずつ書き順と向きを判定し、次に書く場所に番号と矢印を出す。👀おてほん で書き順アニメ、✋ なぞる／みないで 切り替え。書けた文字に ★
- **かず あそび**: たしざん・ひきざん（5まで／10まで）。5マス・10マスに並べた絵を見て、答えの数字を押す。絵をタップすると「いち、に…」と数えてくれる。ひきざんは減るぶんに ✕ がつく

- **ゲーム（ふうせん わり）**: 読み上げた文字（または数 1〜10）の風船をタップして割る。ちがう風船にさわるとその文字を読んで、もう一度お題を言う。10個割るとお祝い

トップで ひらがな／カタカナ を切り替え。

## 手元で動かす
```bash
python -m http.server 8765
```
http://localhost:8765 を開く。

## タブレットに入れる
ホーム画面に追加（PWA）するには HTTPS で公開する必要がある（GitHub Pages など）。公開したURLを Android の Chrome で開き、メニュー →「ホーム画面に追加」。一度開けばオフラインでも動く。

## こえ（ずんだもん）
読み上げは VOICEVOX のずんだもん（ノーマル・速さ0.85・抑揚1.0）で作った MP3（`voice/`、374個・約4MB）。文字・ことば・数字・足し算引き算の問題と答え・ほめことばを用意してある。1文字と数（いち、に…）は弱く聞こえるので、母音を長く・少し高くして「はっきり」させている（`tools/voice-tune.mjs` の EMPHASIS、`build-voice.mjs` の LETTER_EMPHASIS）。全クリップは音量をそろえてから MP3 にしている。「おして きこう」で自由に並べたことばは1文字ずつつなげて読む。

ことばや文を増やしたら、VOICEVOX を起動したまま作り直す（できた分はスキップされる）:
```bash
npm install
```
```bash
npm run voice
```
声の候補を聞き比べるときは `node tools/voice-compare.mjs` で `voice-compare/` にページができる（リポジトリには入れない）。

`tools/voice-readings.tsv` に VOICEVOX の読みが出るので、読み間違いがないか確認する。ひらがな1文字や数字は「は→ワ」「へ→エ」と助詞に読まれるため、スクリプト内でカタカナにして渡している。

音声ファイルがない文だけ端末の音声合成を使う。声が出ないときは Android の設定 →「テキスト読み上げ」で日本語（Google 音声サービス）を入れる。

## ファイル
